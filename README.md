One absurd clause buried deep in a terms-of-service agreement: "By using this service, you agree that your shadow may be sublet to third parties on overcast days." Deadpan legal boilerplate until the absurdity hits: the shadow is sublet, but only when it is overcast.

## Run it

```sh
node main.ts
```

`main.ts` writes the clause to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), verifying first that it is a single sentence of 1–200 characters with no dash.
